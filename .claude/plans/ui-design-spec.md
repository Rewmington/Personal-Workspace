# 个人工作台 · UI 设计规范 v1.0

## 整体风格定位

现代社交 App 的精致感（Telegram + Twitter/X 混合），不是硬核极客/代码编辑器风格。
核心特征：**大圆角、多留白、柔光阴影、通透感**，清爽轻盈。

## 二、字体规范

| 用途 | 字体 | 大小 | 字重 | 行高 |
|------|------|------|------|------|
| 大标题 | Inter | 30px | 800 | 1.2 |
| 小标题 | Inter | 14-16px | 600 | 1.4 |
| 正文 | Inter | 13-14px | 400-500 | 1.5 |
| 标签/说明 | Inter | 10-12px | 500 | 1.3 |
| 数字/代码 | JetBrains Mono | 12-14px | 500 | 1.5 |

- 大标题字间距：`-0.5px`（收紧）
- 标签字间距：`+0.06em`（展开）
- 字体加载：Google Fonts CDN，备用 `-apple-system, BlinkMacSystemFont, sans-serif`

## 六、交互规范

| 状态 | 表现 |
|------|------|
| Tab 当前选中 | 主色半透明背景（手机端）/ 蓝色竖条 + 背景（桌面端） |
| 悬停 | 边框变主色 / 背景微亮 |
| 焦点 | 边框变主色 |
| 拖拽中 | `opacity: 0.55` + `rotate(-1.5deg)` + 强阴影 + 主色边框 |
| 拖拽目标列 | 主色高亮边框 + 顶部主色指示条 |
| 动画过渡 | `0.2s ease` |

---

## 七、图标规范

- 风格：**线性图标**，`stroke-width: 2`，`stroke-linecap: round`，`stroke-linejoin: round`
- 颜色：非激活 `#888888` / 激活态 = 主色
- 尺寸：手机 18-20px / 桌面 20px
- 所有图标使用 **内联 SVG**，不使用外部图标库
